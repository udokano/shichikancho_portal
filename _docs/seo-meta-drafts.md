# AIOSEO メタディスクリプション（投入済み記録）

**2026-07-25 全件 AIOSEO へ投入済み**。管理画面から編集可能な状態（`wp_aioseo_posts` テーブル / `aioseo_options_dynamic`）。このファイルは投入内容の控え。**テーマ PHP にハードコードしない**。

- 固定ページ: 各ページ編集画面 下部「AIOSEO 設定」→ メタディスクリプション（個別投入済み）
- CPTアーカイブ: AIOSEO →「検索の外観」→ コンテンツタイプ → 各タイプの「アーカイブ」タブ（投入済み）
- CPT個別: 同「単一投稿」タブのフォーマットで自動生成（下記「個別投稿」参照）
- トーンはプロトタイプ（Manus 版）のリード文に準拠。プロトタイプ自体はページ別メタを持たないため文面は新規
- 未確定: 運営者名（七間町町内会 / 七間町商店街振興組合）。文中で組織名を名乗る必要がある箇所は確定後に調整
- バックアップ: 投入前の `aioseo_options` / `aioseo_posts` をセッション scratchpad に JSON 保存（セッション消滅で失われる）

## 個別投稿の自動生成フォーマット（投入済み）

「検索の外観 → コンテンツタイプ → 単一投稿」のメタディスクリプション欄。

| CPT | 設定値 | 理由 |
|---|---|---|
| shop | `#custom_field-shop_description` | 抜粋は 10/51 しか無いが ACF は 47/51 |
| spot | `#custom_field-spot_description` | 同上（ACF 25/37） |
| learn_facility | `#custom_field-facility_description` | 本文・抜粋とも空、ACF のみ |
| walk_course | `#custom_field-walk_description` | 同上 |
| resident | `#post_title｜七間町で暮らす人・働く人へのインタビュー。…` | 本文がシードの同一ダミーで8件重複したためタイトルで一意化。**本文が実データに差し替わったら `#post_excerpt` に戻す** |
| column / news / event / job / property | `#post_excerpt`（既定のまま） | 抜粋の充足率が高い |

`#custom_field-` スマートタグは AIOSEO Lite でも動作する（実測）。ACF が空の投稿は AIOSEO が本文から自動生成にフォールバックするため空にならない。

### 再投入の手順（本番移行時）

生 SQL でなく AIOSEO の API を使う。管理画面と同じ保存先になり、UI からも編集できる。

```php
// ページ別
$ap = \AIOSEO\Plugin\Common\Models\Post::getPost( $post_id );
$ap->post_id = $post_id;
$ap->description = '…';
$ap->save();

// アーカイブ / 投稿タイプ別フォーマット
aioseo()->dynamicOptions->searchAppearance->archives->shop->metaDescription = '…';
aioseo()->dynamicOptions->searchAppearance->postTypes->shop->metaDescription = '#custom_field-shop_description';
aioseo()->dynamicOptions->save( true );
```

エリア5ページ（七間町/常磐町/呉服町/鷹匠/馬場町）は `/area/` の子なので `get_page_by_path('tokiwa')` では取得できない。ID 指定（1223〜1227）か `'area/tokiwa'` を使う。

## （参考）検討時の方針メモ

件数が多く手入力は非現実的。AIOSEO の「検索の外観 → コンテンツタイプ → 単一投稿」でスマートタグによる自動生成フォーマットを設定する。

**抜粋（post_excerpt）の充足率**（2026-07-25 実測）

| CPT | 抜粋あり / 全件 |
|---|---|
| shop | 10 / 51 |
| spot | 13 / 37 |
| event | 10 / 13 |
| column | 10 / 10 |
| news | 13 / 13 |
| resident | 10 / 18 |

- **column / news / event** は抜粋がほぼ揃っているので `#post_excerpt` のスマートタグ設定だけで完了する
- **shop** は抜粋が2割しかない一方、ACF `shop_description` は 51件中 47件に入っている。AIOSEO のスマートタグは ACF を直接読めないため、`shop_description` → `post_excerpt` へ一括転記するのが現実的（1回の移行スクリプトで足りる。以降は入稿時に抜粋も埋める運用）
- **spot** も同様に `spot_description` の充足状況を確認したうえで転記する
- 転記後のフォーマット例: `#post_excerpt`（空のときのフォールバックとして `#post_title | 七間町`）
